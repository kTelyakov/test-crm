# Spec Delta

## Purpose

Определяет задачи по объектам: создание, редактирование, удаление, назначение исполнителя и видимость задач для каждой роли, включая экран «Мои задачи».

## ADDED Requirements

### Requirement: Создание задачи
Постановщик SHALL создавать задачу в объекте с названием, описанием, необязательным сроком и исполнителем. Новая задача MUST иметь статус «Новая».

#### Scenario: Создание задачи с исполнителем
- **WHEN** постановщик создаёт задачу в объекте и выбирает исполнителя
- **THEN** задача создаётся в статусе «Новая», назначенной выбранному исполнителю

#### Scenario: Назначать можно только исполнителя
- **WHEN** постановщик пытается назначить задачу пользователю с ролью постановщика
- **THEN** операция отклоняется

#### Scenario: Название обязательно
- **WHEN** постановщик пытается создать задачу без названия
- **THEN** создание отклоняется с ошибкой валидации

### Requirement: Редактирование и удаление задачи
Постановщик SHALL редактировать и удалять задачи. Исполнитель MUST NOT изменять и удалять данные задачи.

#### Scenario: Редактирование задачи постановщиком
- **WHEN** постановщик изменяет название, описание или срок задачи
- **THEN** изменения сохраняются, статус задачи не меняется

#### Scenario: Исполнитель пытается изменить данные задачи
- **WHEN** исполнитель отправляет запрос на редактирование или удаление задачи
- **THEN** запрос отклоняется

### Requirement: Смена исполнителя
Постановщик SHALL менять исполнителя задачи, пока задача находится в статусе «Новая» или «На доработке». В других статусах смена исполнителя MUST быть отклонена.

#### Scenario: Смена исполнителя у новой задачи
- **WHEN** постановщик меняет исполнителя у задачи в статусе «Новая»
- **THEN** задача назначается новому исполнителю

#### Scenario: Смена исполнителя у задачи в работе
- **WHEN** постановщик пытается сменить исполнителя у задачи в статусе «В работе» или «На проверке»
- **THEN** операция отклоняется

### Requirement: Видимость задач
Постановщик SHALL видеть все задачи. Исполнитель SHALL видеть только задачи, назначенные ему.

#### Scenario: Исполнитель открывает чужую задачу
- **WHEN** исполнитель запрашивает задачу, назначенную другому исполнителю
- **THEN** задача не возвращается (как несуществующая)

### Requirement: Экран «Мои задачи»
Исполнитель SHALL иметь экран «Мои задачи» со списком назначенных ему задач и их статусами.

#### Scenario: Список своих задач
- **WHEN** исполнитель открывает «Мои задачи»
- **THEN** он видит только свои задачи из всех объектов с их текущими статусами

#### Scenario: Пустой список
- **WHEN** у исполнителя нет назначенных задач
- **THEN** экран показывает пустое состояние
